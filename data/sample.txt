# AI 本地文档问答工具 使用说明

## 这是什么
这是一个完全运行在你电脑上的文档问答工具。你把 PDF、TXT、MD 文件放进 data 文件夹，它就会把内容切块、转成向量，之后你用大白话提问，它会从文档里找出最相关的段落，交给大模型生成答案。整个过程你的文档不会上传到任何服务器，只有你的问题会发给 DeepSeek。

## 怎么安装
先用 Python 创建一个虚拟环境，然后安装依赖：fastembed 负责本地向量化，openai 负责调用 DeepSeek，streamlit 负责网页界面。安装命令是 pip install -r requirements.txt。配置方面，只需要在 .env 文件里填上 DEEPSEEK_API_KEY 即可，不需要任何付费的 embedding 接口。

## 怎么使用
使用只需两步。第一步运行 ingest 建立索引，把文档变成可检索的向量；第二步运行 ask 加上你的问题。例如问"这个工具怎么用"就能得到基于文档的回答。如果你想知道它参考了文档的哪一段，可以加上 --show-context 参数。网页界面则用 streamlit run 启动，适合给别人演示。

## 支持哪些文件
目前支持三种格式：PDF 文档、纯文本 TXT、以及 Markdown 的 MD 文件。后续可以扩展支持 Word 文档和直接抓取网页。

## 常见问题
问：为什么搜不到关键词但能答出来？答：因为它用的是语义向量检索，不是关键词匹配，所以换种说法也能找到相关内容。问：文档安全吗？答：文档只在本地做向量化，不会离开你的电脑。
